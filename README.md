# Многопоточный банк

Учебный проект по курсу из 14 уроков. Работа ведётся последовательно: сначала запускайте детонатор текущего урока и наблюдайте проблему, затем переходите к материалу следующего урока, который её исправляет.

## Требования

- JDK 21 (в проекте настроен Gradle Java toolchain 21)
- Gradle Wrapper 9.0.0

## Урок 1: lost update

Запустить детонатор:

```powershell
.\gradlew.bat test --tests ru.z3r0ing.AccountConcurrencyTest
```

Тест создаёт 10 потоков, каждый выполняет 100 000 пополнений. Ожидаемый результат курса на этом этапе — падение проверки: итоговый баланс может оказаться меньше `1_000_000` из-за потерянных обновлений. Не исправляйте `Account`, пока не перейдёте к уроку 2.

Полный набор JUnit-тестов запускается командой:

```powershell
.\gradlew.bat test
```

## Профили производительности и гонок

Код бенчмарков размещается в `src/jmh/java`, а jcstress-тестов — в `src/jcstress/java`.

```powershell
.\gradlew.bat jmh
.\gradlew.bat jcstress
```

Эти задачи подготовлены для следующих уроков; до добавления соответствующих сценариев они не запускают учебных измерений.
